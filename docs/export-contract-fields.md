# Export Contract Fields

- Inventory schema: `dagzoo-export-contract-inventory-v1`
- Machine-readable source of truth: `reference/export_contract_inventory.yaml`
- Path patterns use `*` for dynamic map keys and `[]` for list item shapes.
- `audit_status` is a field-review classification only; it does not change the live export surface.

## DatasetBundle

Public in-memory wrapper returned by generate APIs.

| Path              | Type                    | Presence               | Stability | Producer                                                | Audit                              | Known Consumer / Rationale       |
| ----------------- | ----------------------- | ---------------------- | --------- | ------------------------------------------------------- | ---------------------------------- | -------------------------------- |
| `X_test`          | \`torch.Tensor\[float32 | float64\]\`            | always    | `stable`                                                | `dagzoo.core.dataset.generate_one` | `keep`                           |
| `X_train`         | \`torch.Tensor\[float32 | float64\]\`            | always    | `stable`                                                | `dagzoo.core.dataset.generate_one` | `keep`                           |
| `feature_types`   | `list[string]`          | always                 | `stable`  | `dagzoo.core.dataset.generate_one`                      | `keep`                             | emitted feature typing           |
| `feature_types[]` | `string`                | when feature count > 0 | `stable`  | `dagzoo.core.dataset.generate_one`                      | `keep`                             | per-column emitted feature type  |
| `metadata`        | `object`                | always                 | `stable`  | `dagzoo.core.generation_runtime._build_bundle_metadata` | `keep`                             | emitted dataset metadata payload |
| `y_test`          | \`torch.Tensor\[int64   | float\]\`              | always    | `stable`                                                | `dagzoo.core.dataset.generate_one` | `keep`                           |
| `y_train`         | \`torch.Tensor\[int64   | float\]\`              | always    | `stable`                                                | `dagzoo.core.dataset.generate_one` | `keep`                           |
